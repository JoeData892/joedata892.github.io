Recipe Capture

Photograph a printed recipe or dictate your own, and download a file that Paprika can import.

Settings & how to import into Paprika

Get a key at console.anthropic.com → API Keys. Each recipe read costs a few cents.

  1. Download the .yml file from this page (one recipe, or a batch of several).
  2. iPhone/iPad: the file saves to the Files app. In Paprika, open Settings → Import, choose Paprika / YAML file (or just share the file to Paprika from the Files app).
  3. Mac/Windows: in Paprika choose File → Import and select the .yml file.
  4. Paprika syncs the new recipes to your other devices.

How do you want to add this recipe?

1 Photograph the recipe

Add one photo per page if the recipe spans more than one. Lay the page flat in good light.

2 Your changes & notes

1 Dictate your recipe

Talk naturally: say the name, the ingredients with amounts, then the steps, plus any tips. Claude will tidy it up and fix misheard words.

No luck with the button? Tap in the box and use the microphone on your keyboard instead.

2 Turn it into a recipe

3 Review & edit

Claude fills these in for you. Check them and fix anything it got wrong. You can also type a recipe in by hand.

Uses a photo of the finished dish if you add one. In photo mode, it otherwise uses the first page photo.
